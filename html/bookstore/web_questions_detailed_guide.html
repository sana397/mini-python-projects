Web Technologies - Detailed Guide

1. Static Web Pages for Online Book Store

a) Home Page with Frames

Frames allow you to divide the browser window into multiple sections, each displaying a different HTML document. The <frameset> tag replaces the <body> tag when used. Example:

<frameset rows="20%,80%">
  <frame src="header.html">
  <frameset cols="20%,80%">
    <frame src="menu.html">
    <frame src="welcome.html">
  </frameset>
</frameset>

Note: Frames are outdated and not recommended for modern web design, but are still used for learning purposes.

b) Login Page

A login page typically contains a form with username and password fields. Example:

<form>
  Username: <input type="text" name="username"><br>
  Password: <input type="password" name="password"><br>
  <input type="submit" value="Login">
</form>

c) Catalogue Page

The catalogue page uses an HTML table to display book details. Example:

<table>
  <tr><th>Title</th><th>Author</th><th>Price</th></tr>
  <tr><td>Book 1</td><td>Author 1</td><td>$10</td></tr>
</table>

d) Registration Page

The registration page collects user information using a form. Example:

<form>
  First Name: <input type="text" name="fname"><br>
  ...
</form>

2. JavaScript Validation (Registration)

JavaScript is used to validate form fields before submission. Example checks:

  • First Name: Only alphabets, at least 6 characters
  • Password: At least 6 characters
  • Email: Must match pattern name@domain.com
  • Mobile: Exactly 10 digits
  • Last Name and Address: Not empty
// First Name
if (!/^[A-Za-z]{6,}$/.test(fname)) { ... }
// Password
if (password.length < 6) { ... }
// Email
if (!/^\w+([\.-]?\w+)*@\w+([\.-]?\w+)*(\.\w{2,3})+$/.test(email)) { ... }
// Mobile
if (!/^\d{10}$/.test(mobile)) { ... }
// Last Name/Address
if (lname.trim() === "") { ... }
if (address.trim() === "") { ... }

3. CSS Usage

CSS styles HTML elements. There are three ways to use CSS:

  • Inline: Directly in the tag: <h1 style="color:blue;">Title</h1>
  • Internal: In a <style> block in the <head>:
<style> h1 { color: blue; } </style>
  • External: In a separate file (e.g., style.css): <link rel="stylesheet" href="style.css">

4. JavaScript Pop-ups and Functions

JavaScript can interact with users using pop-ups and functions:

  • Display Date: document.getElementById('datebox').value = new Date().toLocaleString();
  • Factorial: Use prompt() to get input, calculate factorial, show with alert()
  • Multiplication Table: Use prompt() and alert() to display table
  • Sum Numbers: Use prompt() in a loop, sum, show with alert()
var n = prompt('Enter n:');
var f = 1; for (var i=1;i<=n;i++) f*=i; alert(f);

5. Country/Capital Selection (with CSS)

Use a <select> dropdown and JavaScript to show the capital. Style the output with CSS:

<select id="country" onchange="showCapital()">...</select>
<span id="capital" class="capital"></span>
.capital { color: brown; font-weight: bold; font-size: 1.2em; }

if (!/^[0-9]{1,3}$/.test(n)) { alert('0-999 only!'); }

7. PHP/Java/XML (Syntax Only)

PHP and Java require a server. Example PHP for sum of digits:

$sum = 0; $n = 123; while ($n > 0) { $sum += $n % 10; $n = (int)($n/10); }

XML for users:

<users>
  <user id="1">...</user>
  ...
</users>

Java: Use DOM/SAX parser to read XML (see Java docs).

9. Calculator (JS)

Simple calculator using JavaScript:

function calc(op) {
  var a = parseFloat(document.getElementById('a').value);
  var b = parseFloat(document.getElementById('b').value);
  var res;
  switch(op) { case '+': res = a+b; break; ... }
  document.getElementById('result').value = res;
}

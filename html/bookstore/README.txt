Online Book Store Project
========================

This mini project demonstrates all major HTML, CSS, and JavaScript concepts:
- Home page with frames
- Login page
- Catalogue page (table)
- Registration page (with validation)
- JavaScript pop-ups and functions
- CSS (inline, internal, external)
- Country/capital selection
- Number-to-words conversion
- Calculator (JavaScript)

Open index.html to start. Each page is linked and demonstrates the requested features.

PHP, Java, and XML examples are described in comments, as they require a server environment.
